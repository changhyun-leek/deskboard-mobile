Deskboard 개인정보 처리방침

시행일 2026년 11월 23일 · Deskboard 웹앱으로

Deskboard는 개인이 자기 과제·시험·일정을 관리하려고 만든 앱입니다. 이 문서는 Deskboard가 구글 계정과 구글 캘린더 정보를 어떻게 다루는지 설명합니다.

구글에 요청하는 권한

권한은 https://www.googleapis.com/auth/calendar.app.created 하나만 요청합니다. 이 권한으로는 Deskboard가 만든 보조 캘린더 「Deskboard」와 그 안의 일정만 만들고, 고치고, 지울 수 있습니다. 주 캘린더와 다른 캘린더는 읽지도 쓰지도 않습니다.

구글 캘린더로 보내는 정보

  • Deskboard에 등록한 과제·시험의 제목, 과목, 마감·시작 시각, 완료 여부
  • 일정 설명에 들어가는 LMS 링크와 메모

이 정보는 사용자 본인의 구글 캘린더에만 기록됩니다.

저장하는 정보와 위치

  • 구글 연결 토큰: 사용자 PC에만 Windows 계정 암호화(DPAPI)로 저장합니다. 서버나 클라우드로 보내지 않으며, 암호화를 쓸 수 없는 환경이면 저장하지 않습니다.
  • 동기화 결과: 보낸 개수, 시각, 오류 내용, 「Deskboard」 캘린더 ID, 연결한 구글 계정 주소를 사용자 본인의 Deskboard 클라우드 저장소에 저장합니다. 휴대폰에서 동기화 상태를 보여 주는 데만 씁니다.

제3자 제공

구글에서 받은 정보를 다른 사람이나 회사에 제공하거나 팔지 않고, 광고에 쓰지 않습니다. Deskboard의 Google API 사용과 데이터 전송은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

연결 끊기와 삭제

  • Deskboard PC 앱의 설정 → 구글 캘린더 → 연결 해제를 누르면 구글에 토큰 취소를 요청하고 PC에 저장된 토큰을 지웁니다.
  • 구글 계정의 서드파티 연결 관리에서도 언제든 권한을 취소할 수 있습니다.
  • 이미 만든 「Deskboard」 캘린더와 일정은 사용자의 구글 캘린더에 남습니다. 필요 없으면 구글 캘린더에서 그 캘린더를 지우면 됩니다.
